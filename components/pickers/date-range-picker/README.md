# Rango de fechas

## Por qué entró

Me encanta para elegir el período de un gráfico específico, por ejemplo los inscriptos a los cursos.

## Sirve para

- filtrar gráficos y reportes por período
- inscriptos a cursos por fecha
- tablero del admin

Origen: [Arc UI](https://uiarc.dev/components/date-range-picker) · licencia desconocida.
Tecnologías: motion, lucide-react, tailwind, css. Dependencias: lucide-react, motion.
