# Mantener para confirmar

## Por qué entró

Confirmar manteniendo apretado, sin pop-up: para eliminar algo importante pero no tan importante.

## Sirve para

- eliminar sin diálogo de confirmación
- acciones importantes pero recuperables

## No sirve para

- borrar algo irreversible o masivo: ahí va una confirmación explícita

Origen: [Arc UI](https://uiarc.dev/components/hold-to-confirm) · licencia desconocida.
Tecnologías: motion, lucide-react, tailwind, css. Dependencias: lucide-react, motion.
