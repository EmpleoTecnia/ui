# Deslizador

## Por qué entró

Buen movimiento y suma valor que te vaya mostrando el número al mover la barra.

## Sirve para

- filtros con rangos numéricos: precio, años de experiencia, cantidad

Origen: [Arc UI](https://uiarc.dev/components/slider) · licencia desconocida.
Tecnologías: motion, tailwind, css. Dependencias: motion.
