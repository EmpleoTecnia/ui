# Selector de color

## Por qué entró

Está genial. Lo único que no tiene y le agregaría es poder elegir en RGB y RGBA.

## Sirve para

- elegir colores de marca, de etiquetas o de categorías
- personalización de una empresa

## No sirve para

- tal como viene, sin RGB/RGBA: habría que agregarlo al portear

Origen: [Arc UI](https://uiarc.dev/components/color-picker) · licencia desconocida.
Tecnologías: motion, lucide-react, tailwind, css. Dependencias: lucide-react, motion.
