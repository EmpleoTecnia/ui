# Campo con menciones

## Por qué entró

Para etiquetar personas en un chat: la mención resalta muy bien en la conversación.

## Sirve para

- chats y comentarios donde se etiqueta gente
- mensajes entre el equipo y con empresas

Origen: [Arc UI](https://uiarc.dev/components/mention-input) · licencia desconocida.
Tecnologías: motion, lucide-react, tailwind, css. Dependencias: lucide-react, motion.
