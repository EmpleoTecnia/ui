# Campo numérico

## Por qué entró

La dinámica: la alerta cuando llegás al máximo y cómo te va sumando el precio a medida que agregás.

## Sirve para

- agregar personas o licencias a un equipo
- cantidades con precio total

Origen: [Arc UI](https://uiarc.dev/components/number-field) · licencia desconocida.
Tecnologías: motion, lucide-react, tailwind, css. Dependencias: lucide-react, motion.
