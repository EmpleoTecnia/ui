# Editor de texto

## Por qué entró

No tiene las opciones fijas arriba: se van mostrando a medida que seleccionás una parte del texto.

## Sirve para

- descripciones de cursos, eventos y ofertas
- mensajes con formato

Origen: [Arc UI](https://uiarc.dev/components/rich-text-editor) · licencia desconocida.
Tecnologías: motion, lucide-react, tailwind, css. Dependencias: lucide-react, motion.
