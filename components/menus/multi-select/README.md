# Selección múltiple

## Por qué entró

Elegís sin checkbox, no te saca del desplegable cada vez que elegís uno y te va mostrando arriba lo que fuiste agregando.

## Sirve para

- elegir varias etiquetas, personas o categorías en formularios y filtros

Origen: [Arc UI](https://uiarc.dev/components/multi-select) · licencia desconocida.
Tecnologías: motion, lucide-react, tailwind, css. Dependencias: lucide-react, motion.
